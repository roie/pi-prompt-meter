# pi-prompt-meter

A small Pi extension for per-prompt time and usage.

```text
Working · 02:14 · ↑42k ↓6.1k R1.8M · $0.041 (sub)
```

When the prompt settles, the final result remains visible until the next prompt.

```text
Last · 04:37 · ↑73k ↓11k R3.2M · $0.086 (sub)
```

## Install

```bash
pi install npm:pi-prompt-meter
```

Pi 0.84.4 or newer is required.
